# Skills

Agent Skills by Jon (NoisemakerJon). Each skill is a folder under `skills/` with a `SKILL.md`.
Most are adapted from posts people shared on X, and credit their source.

Browse them on [skills.sh](https://skills.sh/noisemaker111/skills).

## Install

```sh
npx skills add noisemaker111/skills --skill <name>
```

List what is here:

```sh
npx skills add noisemaker111/skills --list
```
